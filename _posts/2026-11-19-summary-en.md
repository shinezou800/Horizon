### [Unauthenticated Remote Code Execution Vulnerabilities Discovered in Nginx HTTP/2](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities) ⭐️ 9.0/10

Wiz security research analyzed unauthenticated remote code execution vulnerabilities in Nginx associated with HTTP/2, tracked as CVE-2026-123633 and CVE-2026-123007. The disclosures highlight severe risks for internet infrastructure running vulnerable configurations. While HTTP/2 is not enabled by default in Nginx, affected servers face critical remote compromise vectors.

hackernews · speedping · Nov 18, 15:19 · [Discussion](https://news.ycombinator.com/item?id=50547374)

**「Background」** Nginx is a widely deployed open-source web server and reverse proxy that supports the multiplexed HTTP/2 protocol, a complex standard designed to improve web performance over a single TCP connection. Protocol implementations of this complexity have historically introduced intricate parsing and memory management challenges.

**「Impact」** Administrators running Nginx with HTTP/2 enabled should review their configurations and apply patches or disable HTTP/2 as an immediate workaround to mitigate potential unauthenticated remote code execution.

**「Community Discussion」** Commenters noted that the fixes appeared in public repositories a week before official advisories, potentially exposing unpatched systems, though others pointed out that HTTP/2 is not enabled by default and requires specific traffic volumes or conditions to exploit.
